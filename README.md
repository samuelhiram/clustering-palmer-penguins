# Clustering Palmer Penguins

> Unsupervised clustering of the Palmer Penguins dataset, comparing K-Means, DBSCAN and Agglomerative.

A short data-mining study built around **Science 2.0** practices: public data, open code and
reproducible experiments. The question it answers is whether natural groupings of penguins can be
discovered automatically from physical measurements alone — without ever showing the algorithm the
species label — and how three different clustering families compare when you do.

**Status:** Complete · Coursework, Data Mining (delivered 26 May 2026) · **Language:** Python / Jupyter

## Dataset

**Palmer Penguins** — 344 observations of 3 species (Adelie, Chinstrap, Gentoo) collected in the
Palmer Archipelago, Antarctica, by Dr. Kristen Gorman.

| | |
|---|---|
| License | CC-0 |
| Source | https://github.com/allisonhorst/palmerpenguins |
| Features | `bill_length_mm`, `bill_depth_mm`, `flipper_length_mm`, `body_mass_g` |
| Labels | `species`, `island`, `sex` — held out from the algorithms, used only to score them |

## Methods compared

| Algorithm | Hyperparameters | Trade-off |
|---|---|---|
| K-Means | `k=3` | Fast, but the cluster count must be known in advance |
| DBSCAN | `eps=0.5`, `min_samples=5` | Infers the cluster count and flags noise automatically |
| Agglomerative | `n_clusters=3`, `linkage=ward` | Hierarchical, produces a full merge tree |

Scored with **Silhouette Score**, **Adjusted Rand Index** against the true species label, and a
confusion matrix.

Every random seed is pinned to `RANDOM_STATE = 42`, and the notebook runs start to finish with no
manual intervention. Re-running it on a clean machine reproduces every figure and metric in the
report.
